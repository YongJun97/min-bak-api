숙박 PMS 웹사이트 (Airbnb Clone)
프로젝트 개요

에어비앤비(Airbnb)를 모티브로 한 숙박 관리(PMS, Property Management System) 웹사이트입니다.
게스트, 호스트, 관리자(Admin)의 권한에 따라 각기 다른 기능을 제공하며,
숙소 등록 → 예약 → 결제 → 관리까지의 전 과정을 구현했습니다.

<주요 기능>
-회원가입 & 인증

ㄴ게스트/호스트

ㄴ일반 회원가입 (세션 기반 로그인) 및 네이버/구글 소셜 로그인(OAuth2) 지원

ㄴ회원가입 완료 시 게스트 권한 부여 → 숙소 등록 완료 시 호스트 권한으로 전환

ㄴJWT 기반 인증 (Access/Refresh Token 발행, Refresh Token DB 저장 및 관리)

ㄴ로그아웃 시 Refresh Token 및 쿠키 무효화 처리

-관리자(Admin)

ㄴ세션 기반 로그인 (JSESSIONID 발급)

ㄴ로그아웃 시 세션 무효화 및 JSESSIONID 삭제

<예약 & 결제>

-게스트

ㄴ숙소 검색 및 선택 → 예약 신청

ㄴ예약 완료 시 상태는 대기 중 → 호스트 승인 후 결제 가능

ㄴPortOne API 연동 결제 (카카오페이, KG이니시스, 토스페이, 페이팔 등)

ㄴ결제 완료 시 DB 저장 및 숙소 이용 가능

-호스트

ㄴ본인의 숙소 관리 페이지에서 예약 현황 확인

ㄴ대기 상태 예약을 수락/거절 가능

<숙소 등록 (호스트)>

ㄴ모든 사용자는 기본적으로 게스트 권한으로 시작

ㄴ단계별 등록 프로세스: 입력 데이터를 세션에 저장 후 최종 제출

ㄴ숙소 등록 완료 시 호스트 권한 자동 부여

ㄴ영업신고증 등록 필수 → 관리자 승인 후 숙소 상태 활성화

<관리자(Admin) 기능>

ㄴ등록된 숙소 조회 및 검색 기능 제공

ㄴ신고 접수된 숙소 확인 및 제재 처리

ㄴ예약/결제 내역 관리

ㄴ사용자 리뷰 모니터링 및 관리

<담당 역할 (숙소 관련 기능 중심)>

-숙소 등록 프로세스 구현

-단계별 입력 페이지 구성 및 세션 기반 데이터 저장

-최종 제출 시 DB에 숙소 등록 처리

-호스트 권한 전환 로직 개발

-숙소 등록 완료 시 게스트 → 호스트 권한 자동 부여

-영업신고증 등록 및 승인 관리

-관리자가 영업신고증을 확인 후 숙소 상태 활성화

-예약 및 결제 기능 개발

-예약 신청, 대기/승인 처리

-PortOne API 연동 결제 기능 구현 (카카오페이, KG이니시스, 토스페이, 페이팔 등)

-결제 완료 후 숙소 이용 가능 처리

-관리자(Admin) 연동 기능 구현

등록 숙소 상태 관리 및 승인 기능

예약 상태 확인 및 결제/리뷰 관리 지원
